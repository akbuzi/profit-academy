# Учебный многостраничный сайт «ProIT Academy»

Данный проект разработан в рамках Лабораторно-практической работы №8.

## Структура проекта:
- `index.html` — Главная страница
- `courses.html` — Каталог учебных направлений
- `about.html` — Информация о проекте
- `contacts.html` — Контактная информация
- `css/style.css` — Стили оформления
- `robots.txt` — Инструкции для поисковых роботов
- `sitemap.xml` — Карта сайта XML

## Используемые технологии:
- HTML5 (Семантическая разметка, Open Graph, SEO meta)
- CSS3 (Адаптивная верстка, Flexbox)
- GitHub Pages
